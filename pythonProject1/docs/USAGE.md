# 使用说明

## 1. 打开页面

电脑端推荐使用 Edge 或 Chrome 打开 `index.html`。

如果需要手机访问，先在电脑上启动本地服务和公网隧道，再用手机访问终端里打印出来的 HTTPS 链接。

## 2. 摄像头权限

页面需要调用摄像头做手势识别。第一次打开时，浏览器会请求摄像头权限，请选择允许。

如果没有弹出权限提示，可以尝试：

- 刷新页面。
- 点击页面里的“启动摄像头”按钮。
- 检查浏览器地址栏里的摄像头权限。
- 换 Edge、Chrome、QQ 或微信内置浏览器测试。

## 3. 手势对应效果

| 手势 | 页面效果 |
| --- | --- |
| 手掌张开 / 画面中手变大 | 粒子分散 |
| 手掌收缩 / 画面中手变小 | 粒子聚拢 |
| 手掌向左移动 | 爱心向左平移 |
| 手掌向右移动 | 爱心向右平移 |
| 快速左右挥动 | 爱心左右旋转 |
| 上下移动或旋转手掌 | 爱心产生上下旋转反馈 |

## 4. 控制菜单

页面菜单可用于调节：

- 粒子颜色
- 粒子大小
- 爱心/其他形状
- 跟随速度
- 旋转强度
- 摄像头开关
- 全屏显示

如果某些手机浏览器不显示菜单，优先使用 Edge、Chrome、QQ 或微信内置浏览器。

## 5. 性能建议

如果手机卡顿：

- 关闭其他后台应用。
- 关闭手机 VPN 或代理。
- 使用手机 QQ/微信内置浏览器或 Chrome。
- 降低粒子数量和粒子大小。
- 使用 Cloudflare Tunnel 的 HTTP2 启动方式。

## 6. 关闭页面

电脑端直接关闭浏览器即可。

如果使用 Cloudflare Tunnel 或 Ngrok，关闭方式是：

```powershell
Ctrl+C
```

或者直接关闭对应的 PowerShell 窗口。
